II МУҚАДДИМА ВА ЗАМИНАИ ПАЙДОИШ

2.1. Мушкилоти мавҷудаи соҳа

То соли 2025 идоракунии равандҳои таълимӣ дар ноҳияи Зафаробод — ки дорои 25 муассисаи таълимӣ, 1048 омӯзгор ва 16 700 хонанда мебошад — асосан бо воситаи асноди коғазӣ ва ҷадвалҳои парокандаи электронӣ ба роҳ монда мешуд. Ин вазъият чанд мушкилоти сохторӣ эҷод мекард:

  • Бори вазнини коғазбозӣ. Ҳар омӯзгор дар як соли таълимӣ дафтари синфӣ, журнали холҳо, варақаҳои тарификатсия ва ҳисоботи чорякиро дастӣ пур мекард. Завучҳо ҳар сол ҳафтаҳоро барои тартиб додани тақсимоти соатҳои дарсӣ сарф менамуданд.
  • Ношаффофии баҳогузорӣ. Баҳои хонандагон дар зинҷири «дафтари омӯзгор → журнали синф → ҳисоботи мактаб → шӯъбаи маориф» се-чор бор дастӣ такрор мешуд ва дар ҳар марҳила имкони хатои инсонӣ ва дахолати субъективӣ вуҷуд дошт.
  • Набудани мониторинги воқеии вақт. Шӯъбаи маориф ҳолати воқеии ҳар мактабро танҳо пас аз гирдиҳамоии ҳисоботи моҳона мешинохт — яъне бо таъхири 15–30 рӯз. Қарорҳои идоравӣ ба маълумоти куҳнашуда такя мекарданд.
  • Инфиродии маълумот. Номгӯйи синфҳо («10а», «10-А», «10 а») ва фанҳо («ОДХ», «ОИХ», «OIH») дар муассисаҳои гуногун ягона набуд ва ҷамъбасти автоматии маълумоти ноҳияро душвор месохт.

2.2. Мувофиқати стратегӣ

Лоиҳа мустақиман ба санадҳои миллии стратегӣ хидмат мекунад:

  • «Бистсолаи омӯзиш ва рушди фанҳои табиатшиносӣ, дақиқ ва риёзӣ (2020–2040)» — рақамикунонии инфраструктури таълимӣ шарти аввалиндараҷаи рушди фанҳои дақиқ аст;
  • Консепсияи гузариш ба таҳсилоти рақамӣ дар Ҷумҳурии Тоҷикистон — платформа намунаи амалии ин консепсия дар сатҳи як ноҳияи алоҳида мебошад;
  • Стандартҳои Вазорати маориф ва илми ҶТ — миқёси миллии 10-хола, тақсимбандии чорякӣ ва ҳуҷҷатнигории давлатӣ дар пояи система гузошта шудааст.
ҲАДАФ
Сохтани системаи рақамии ягонае, ки тамоми занҷири идоракунии маорифро — аз холи ҳаррӯзаи хонанда то мониторинги шӯъбаи маориф — дар як фазои иттилоотии муттаҳид муттаҳид месозад, бори маъмуриро кам мекунад ва шаффофияти пурраи баҳогузориро таъмин менамояд.

3.2. Амният ва эътимоднокӣ

  • RBAC: се нақши асосӣ — Раиси маориф, Директори муассиса (завуч), Омӯзгор — бо ҳуқуқҳои фарқкунанда дар сатҳи ҳар view ва ҳар объекти маълумот;
  • QuarterLock — қуфли чорякӣ: пас аз супоридани холҳои чоряк давра аз ҷониби маъмурият механикӣ баста мешавад; тағйири баҳои басташуда аз ҷониби омӯзгор имконнопазир аст;
  • Даври тасдиқ (SubjectDeactivationRequest): хориҷкунии фан танҳо бо тасдиқи суперадмин — сепаратсияи ҳуқуқҳо;
  • Audit trail: ҳар сабт муаллиф, сана ва ҳолат дорад — имкони тафтиши пурраи оморӣ;
  • HTTPS + калидҳои криптографии SSH: интисоли маълумот ва насбкунӣ танҳо аз каналҳои рамзгузоришуда.

3.3. Мутобиқати миллӣ

  • Миқёси баҳогузории 10-хола — стандарти Вазорати маориф ва илми ҶТ;
  • Алифбои 35-ҳарфаи тоҷикӣ дар саросари интерфейс (Ӯ, Қ, Ғ, Ҳ, Ҷ, Ӣ);
  • Се забони таълимӣ — тоҷикӣ, ӯзбекӣ, русӣ;
  • Нормализатсияи худкор: 10a / 10-a / 10 а → 10-А · ОДХ / OIH / OIX → ОИХ.

5.1. Алгоритми таснифоти дуфарҳангаи ҷинсият TAJIK–UZBEK ONOMASTIC CLASSIFIER

Масъала. Дар базаи 16 700 хонанда майдони «ҷинс» вуҷуд надошт — муассисаҳо ҳам бо номгузории тоҷикӣ (-зода, -ӣ, шарифи «духтар»/«писар»), ҳам бо суннати ӯзбекӣ (-қизи, -ўғли, -оглы) ва ҳам русӣ (-ова, -овна) пур шуда буданд. Ташхиси дастии 16 700 ном ғайриимкон буд.

Ҳал — таснифгари ономастикии бисёрқабата (portal/gender_detector.py):

Ному насаб │ ▼ [1] Нормализатсияи кирилликӣ (нишонаҳо, ҳарфҳои калон → хурд) │ ▼ [2] Таҳлили ШАРИФ: │ «қизи/кизи/овна/евна/духт» → ДУХТАР │ «ўғли/угли/ович/евич/пур/оглы» → ПИСАР ▼ [3] ОХИРИ НАСАБ: │ «-ова/-ева/-ина» → ДУХТАР «-ов/-ев/-ин» → ПИСАР │ «-зода/-ӣ/-ён» → ХОНУСОР (қабати 4) ▼ [4] ЛУҒАТИ НОМҲО (дукорпусии тоҷикӣ-ӯзбекӣ): │ 300+ номи занона (мадина, зебунисо, гулнор…) │ 300+ номи мардона (рустам, алишер, мақсуд…) ▼ [5] ПРЕФИКСҲОИ ҶИНСАТӢ: │ «биби-», «гул-», «моҳ-», «дил-» → ДУХТАР │ «абду-», «муҳаммад», «мулло-», «мирзо-» → ПИСАР ▼ [6] ОХИРИ НОМИ ХУСУСӢ: «-хон/-бону/-бегим/-нисо» → ДУХТАР «-бек/-ҷон/-қул/-шоҳ» → ПИСАР

Натиҷаи амалӣ: алгоритм 98,8%-и ҳамаи 16 700 хонандаро дуруст тасниф кард; 1,2%-и боқимонда (номҳои хонусори ҳақиқӣ) ба рӯйхати омӯзгори синф барои тасдиқи якдафъаина мебарояд. Ин тасниф дар ҳеҷ платформаи хориҷӣ, ки барои фазои номгузории Осиёи Марказӣ тарҳрезӣ нашудааст, вуҷуд надорад.

5.2. Алгоритми Dense Ranking РЕЙТИНГИ ЗИЧ

Масъала. Ҳолате пеш меояд, ки ду ё се иштирокчӣ GPA-и яксон доранд. Рейтинги оддӣ пас аз ҷойи муштарак зинаро мепартояд (1, 2, 2, 4) ва маънии ҷойи «3»-ро халалдор месозад.

Ҳал: рақами ҷой танҳо он вақт афзоиш меёбад, ки GPA-и нав аз GPA-и қаблӣ фарқ кунад:

rank = 0 prev_gpa = None for item in data_sorted_by_gpa_desc: if item['gpa'] != prev_gpa: # ҷойи нав танҳо бо GPA-и нав rank += 1 prev_gpa = item['gpa'] item['rank'] = rank # GPA-и баробар → ҷойи баробар Натиҷа: 1, 2, 2, 3 — зинаҳои баробар муштарак, пайдарпайӣ солим

Алгоритм дар се сатҳ амал мекунад: мактабҳо дар ноҳия, синфҳо дар мактаб ва ноҳия, хонандагон (Top-100) дар ноҳия.

5.3. Кӯпруки динамикии ҷорӣ–чорякӣ LIVE DAILY-TO-QUARTER BRIDGE

  1. Харитаи сана → чоряк. Ҳар холи ҳаррӯза бо санаи худ ба чоряки мувофиқ вобаста мешавад (сен–ноя → I, дек–фев → II, мар–май → III, июн–авг → IV);
  2. Прогнози зинда (live projection). Функсияи calc_quarterly() аз холҳои ҷории чоряк пешбинии кушод месозад — нимсола, солона ва ниҳоӣ низ рекурсиван аз қисмҳои мавҷуда прогноз мегиранд;
  3. Нишондиҳандаи «Ҷ» (Ҷорӣ). Ҳар арзиши пешбинишуда бо парчами каҳрабоӣ маркер мегирад — пешбина ҳеҷ гоҳ бо баҳои расмӣ омехта намешавад;
  4. Гузариш ба расмӣ. Баҳои тасдиқшуда афзалият мегирад; пас аз мӯҳлат QuarterLock давраро механикӣ мебандад.
Нимсола₁ = std_round((Q1 + Q2) / 2)
Солона   = std_round((Нимсола₁ + Нимсола₂) / 2)
Ниҳоӣ    = std_round((Солона + Аттестатсия) / 2)

Ҳар гоҳ қисми ростӣ вуҷуд надорад — прогнози ҷонибдор аз қисми мавҷуда, бо парчами _proj = True.

VIII САВОЛУ ҶАВОБҲО БО ҲАКАМОНИ ОЗМУН

Дувоздаҳ саволи пешбинишудаи ҳаяти ҳакамон — профессорон, кормандони Вазорати маориф ва илм ва мутахассисони IT — бо ҷавобҳои асоснок.

01Чаро системаҳои омодаи хориҷӣ (масалан, Кунделик ё дигар платформаҳо)-ро нахаридед ва худатон сохтед?
Ҷавоб

Се далели принсипиалӣ. Якум, мутобиқати миллӣ: платформаҳои хориҷӣ барои алифбои 35-ҳарфаи тоҷикӣ, миқёси махсуси 10-холаи мо, номгузории синфҳои мо («10-А» бо ҳарфи кирилликӣ) ва сохтори чорякии мо тарҳрезӣ нашудаанд — мутобиқсозии онҳо як лоиҳаи алоҳидаи чандмоҳа мешуд. Дуюм, соҳибиятии маълумот: маълумоти 16 700 хонандаи тоҷик бояд дар инфраструктури мо, таҳти назорати мо ва мувофиқи қонунгузории ҶТ нигоҳ дошта шавад, на дар серверҳои ширкати хориҷӣ. Сеюм, иқтисодӣ: платформаи мо арзиши обунавӣ надорад — ҳаргиз барои шӯъбаи маориф ҳисоби моҳона намерасад. Илова бар ин, мо функсияҳое дорем, ки дар ҳеҷ платформаи омода нестанд — масалан, таснифгари ономастикии тоҷикӣ-ӯзбекӣ барои ҷинсият, ки барои таркиби дуфарҳангаи ноҳияи мо зарур буд.

02Амнияти маълумоти шахсии 16 700 хонанда чӣ гуна ҳимоя мешавад?
Ҷавоб

Амният дар чор қабат сохта шудааст. Қабати дастрасӣ: RBAC — ҳар корбар танҳо он маълумотро мебинад, ки ба нақши ӯ ва муассисаи ӯ вобаста аст; омӯзгори мактаби №12 физикан наметавонад хонандаи мактаби №20-ро бинад. Қабати иттисол: тамоми трафик аз роҳи HTTPS рамзгузорӣ мешавад, паролҳо бо hashing-и муосири Django нигоҳубин мегарданд. Қабати барнома: муҳофизати CSRF, SQL-injection ва XSS дар сатҳи фреймворк гарантияшудааст. Қабати идоравӣ: QuarterLock тағйири баҳои тасдиқшударо манъ мекунад ва ҳар сабт муаллифу санадор аст — ҳатто дохили система ҳеҷ кас наметавонад ношинос тағйирот ворид кунад. Паролҳои омӯзгорон тавассути «калидҳои мастер»-и якдафъаина дода мешаванд, ки ивазкунии онҳо ҳангоми аввалин вуруд ҳатмӣ аст.

03Агар дар мактабҳои дурдаст интернет қатъ шавад, система чӣ гуна кор мекунад?
Ҷавоб

Ин савол барои ноҳияи мо, ки мактабҳояш дар нуқтаҳои кӯҳӣ паҳн шудаанд, амалӣ аст. Вокуниши мо дукарата аст. Техникӣ: интерфейс бо Vanilla JS ва CSS3-и сабук сохта шудааст — саҳифаҳо ҳатто дар суръати 3G/2G-и суст бор мешаванд, зеро ҳеҷ китобхонаи вазнини хориҷӣ бор намешавад. Ҷубронӣ: омӯзгор метавонад холҳоро дар Excel-и офлайн ҷамъ кунад ва ҳангоми пайдо шудани интернет бо импорти якдафъаина ворид созад. Ва нуқтаи муҳим: холҳо тақвимӣ ҳифз мешаванд — омӯзгор метавонад холҳои рӯзҳои гузаштаро ворид кунад ва система онҳоро ба чоряки дуруст худкор вобаста мекунад.

04Оё система ба стандартҳои Вазорати маориф ва илми ҶТ, аз ҷумла миқёси 10-хола, мутобиқ аст?
Ҷавоб

Бале, ва на танҳо мутобиқ — система ин стандартҳоро ҳақиқатан иҷро мекунад. Миқёси 10-хола дар модели Grade ҳамчун воҳиди асосӣ гузошта шудааст; тақсимбандии чорякӣ бо QuarterGrade ва ҷадвали аттестатсия (quarter=0) сохтори расмии соли таълимии ҶТ-ро такрор мекунад; нақшаи фанҳо (TJC_SUBJECTS) бевосита аз нақшаи таълимии миллӣ гирифта шудааст ва ҳангоми сабти хонанда фанҳои синфаш худкор бор мешаванд. Синфҳои 0 ва 1 ҳамчун «ғайрибаҳогузорӣ» қайд шудаанд. Ҳуҷҷатҳои содиркардашуда (тарификатсия, ҳисоботҳо) дар формати ҳуҷҷатҳои давлатии Word/Excel мебароянд.

05Мутобиқати забонӣ ва ҳуруфи 35-ҳарфаи тоҷикӣ чӣ гуна ҳал шудааст?
Ҷавоб

Тамоми интерфейс, моделҳо ва ҳуҷҷатҳо бо алифбои расмии кирилликии тоҷикӣ — бо ҳуруфи муштараки Ӯ, Қ, Ғ, Ҳ, Ҷ, Ӣ — сохта шудаанд, на бо имитацияи ҳарфҳои русӣ. Ду сатҳи ҳимояи забонӣ вуҷуд дорад: аввал, CLASS_LETTERS — сатри расмии 35 ҳарф бо тартиби стандартӣ — барои нормализатсияи номи синфҳо; дуюм, функсияи normalize_subject() вариантҳои сабтии фанҳоро (масалан, «ОДХ», «OIH») ба шакли дурусти «ОИХ» мегардонад. Дастгирии се забон (тоҷикӣ, ӯзбекӣ, русӣ) мувофиқи забони таълимии ҳар муассиса аст — мактаби ӯзбекзабони ноҳия бо ҳуруфи ӯзбекӣ сабт мешавад ва ҳеҷ талаффузи забонӣ гум намешавад.

06Сервер дар куҷо ҷойгир аст ва чаро меъмории Python/Django интихоб шуд?
Ҷавоб

Сервер — VPS-и Ubuntu Linux дар нуқтаи 169.58.154.191, ки мо пурра идора мекунем — на хостинги муштарак, на инфраструктури хориҷӣ; ин соҳибияти пурраи маълумотро таъмин мекунад. Django интихоб шуд, зеро се хусусияти беҳамто дорад: (1) ORM барои моделҳои мураккаби таълимӣ — School→Student→Grade→QuarterGrade→QuarterLock — бо транзакцияҳои атомӣ; (2) системаи аутентификатсия ва RBAC-и воридшуда беҳтарин асос барои нақшҳои сеяки мост; (3) экосистемаи Python — pandas, openpyxl, python-docx, paramiko — импорти Excel, ҳуҷҷатҳои Word ва синхронизатсияи дурдастии SSH-ро бе фреймворки иловагӣ ҳал кард. Python 3.12 интихоби оянда низ ҳаст — забонест, ки ҳам барои веб, ҳам барои таҳлили маълумот ва ҳам барои ML кор мекунад.

07Чӣ гуна исбот мекунед, ки система дар амал кор карда истодааст, на дар рӯи коғаз?
Ҷавоб

Далелҳо амалӣ ва санҷишпазиранд. Якум, маълумоти зинда: дар база ҳоло 25 муассиса, 1048 омӯзгор ва 16 700 хонанда сабт шудаанд — ман метавонам ҳоло ворид шуда, ҳар мактабро нишон диҳам. Дуюм, рӯйдодҳои воқеӣ: QuarterLock-ҳо бо locked_at-и воқеӣ, дархостҳои SubjectDeactivationRequest бо санаҳои дархост ва баррасӣ — таърихи амалиёти маъмурӣ дар база мӯҳр хӯрдааст. Сеюм, инфраструктури воқеӣ: GitHub Actions ҳар push-ро ба сервери production мебарад — deploy.log нишон медиҳад, ки ин системаи зиндаест, на презентатсия. Чорум, истифодаи воқеӣ: омӯзгорон бо «калидҳои мастер»-и якдафъаина ворид мешаванд — таърихи истифода дар база ҳаст. Ман омодаам ҳар саҳифаро ҳоло дар назди ҳакамон нишон диҳам — на видео, на скриншот, балки системаи зинда.

08Мушкилоти омӯзгорони калонсол, ки саводи рақамӣ надоранд, чӣ гуна ҳал карда мешавад?
Ҷавоб

Мо онро се роҳ ҳал кардем. Якум — интерфейси интуитивӣ: журнали электронӣ амалан ҳамон ҷадвали коғазии омӯзгор аст, танҳо дар экран — хол гузоштан як клик аст, на формаи мураккаб. Дуюм — ҳуҷҷатҳои таълимӣ: се дастури алоҳида (барои омӯзгор, завуч ва раиси маориф) бо забони содда ва скриншотҳои қадам-ба-қадам тавлид шудааст — ҳар омӯзгор ҳуҷҷати дастрас дорад. Сеюм — модели «воситаи рақамӣ»: дар ҳар мактаб завуч ё омӯзгори ҷавон ҳамчун нуқтаи дастгирии аввалин хидмат мекунад — омӯзгори калонсол метавонад холҳоро дар коғаз нависад ва бо ёрии ҳамкор ворид кунад. Ва муҳимтарин — ҳеҷ ҷойи система имлои англисӣ, менюҳои чандсатҳӣ ё терминологияи техникӣ талаб намекунад; ҳама тоҷикӣ, ҳама оддӣ.

09Таснифоти ҷинсият (писарон ва духтарон) ба чӣ хотир лозим буд?
Ҷавоб

Се сабаби амалӣ ва оморӣ. Якум, ҳисоботи давлатӣ: шӯъбаи маориф шумораи духтарон ва писаронро дар ҳар муассиса ва сатҳи синф гузориш медиҳад — ин қисми ҳисоботи расмии омор аст ва бидуни ҷинсият номумкин буд. Дуюм, таҳлили таълимӣ: мониторинги фарқи иқтибоси духтарон ва писарон дар фанҳои гуногун — масалан, оё духтарон дар физика хуб таҳсил мекунанд — барои сиёсати таълимӣ зарур аст. Сеюм, интихоби олимпиадавӣ ва касбӣ: рӯйхатҳои олимпиадаҳо аксар вақт бо тақсимоти ҷинсӣ талаб мешаванд. Ва муҳим — ҳеҷ платформаи хориҷӣ барои номгузории тоҷикӣ-ӯзбекии мо ин корро намекард; таснифгари мо морфемаҳои миллии мо — «-зода», «-пур», «-қизи», «-ўғли», «-хон», «-бону» — мефаҳмад ва 98,8% дақиқ кор кард. Ин на танҳо функсия, балки ҳалли як масъалаи забоншиносии ҳақиқӣ аст.

10Барои татбиқи ин система дар тамоми вилоят ё ҷумҳурӣ чӣ қадар вақт ва маблағ лозим аст?
Ҷавоб

Архитектураи мо аз аввал барои миқёс тарҳрезӣ шудааст. Замон: барои вилояти Суғд (тақрибан 14 ноҳия, ~700 муассиса) ҳудуди 3–4 моҳ — на солҳо: қадами асосӣ гузариш аз SQLite ба кластери PostgreSQL ва ҳамоҳангсозии ҳуқуқҳои вилоятӣ аст, на навсозии лоиҳа. Маблағ: хароҷоти асосӣ сервер аст — кластери миёнаи PostgreSQL + VPS-и мӯътадил барои тамоми вилоят ҳудуди чанд ҳазор доллар дар сол мешавад, на даҳҳо ҳазор; инфраструктури софтверӣ аллакай мавҷуд аст, зеро ҳеҷ лицензияи моҳона нест. Инсонӣ: дар ҳар ноҳия як администратори маҳаллӣ (одатан ҳамон омӯзгори информатика) кифоя аст — модели мо нишон дод, ки як нафар метавонад 25 муассисаро идора кунад. Барои тамоми ҷумҳурӣ — 6–8 моҳ, бо хароҷоти ҳануз хеле пасттар аз хариди як платформаи хориҷӣ.

11Чӣ гуна аз ворид шудани баҳоҳои бардурӯғ ё тағйир додани баҳо аз ҷониби шахсони бегона пешгирӣ мешавад?
Ҷавоб

Механизми ҳимоя чорқабат аст. Якум — ҳуқуқи қатъӣ: функсияи can_edit_grade_journal() тафтиш мекунад, ки омӯзгор танҳо ба фанҳои таъйиншудааш (allocated_teacher) ва танҳо дар муассисаи худ дастрасӣ дорад — омӯзгори математика физикан наметавонад холҳои таърихро тағйир диҳад. Дуюм — қуфли чорякӣ: QuarterLock пас аз тасдиқ давраро мебандад; ҳар тағйири баҳои басташуда дар сатҳи барнома рад мешавад, на танҳо дар сатҳи интерфейс. Сеюм — даври тасдиқ: ҳатто амалҳои ҳасас, монанди хориҷкунии фан, ба марҳилаи дуюми суперадмин мераванд — ихтиёри як танҳо барои харобкорӣ нест. Чорум — аудит: ҳар Grade муаллиф, сана ва ҳолат дорад; ҳар тағйирот сабт ва пайгирӣ мегардад. Яъне система на танҳо аз бегона, балки аз ихтиёри зиёдатии дохилӣ низ ҳимояшуда аст.

12Масъалаи тақсимоти соатҳо (тарификатсия) ва бори омӯзгорон дар система чӣ гуна шаффоф шуд?
Ҷавоб

Ин яке аз вазифаҳои аз ҳама вақтталаби завуч буд — ҳар сол ҳафтаҳо — ва мо онро бо интерфейси нави се-қисма ҳал кардем. Саҳифаи lesson_allocation се сутун дорад: чап — фанҳои синфҳо, ки ҳануз омӯзгор надоранд (бо нишони ⚠ ошкоршуда); миёна — омӯзгорон бо бори ҷорӣ («14/18 соат» — 14 соати таъйиншуда аз 18 соати намунавӣ); рост — таъйинотҳои ҷорӣ. Система худкор ҳисоб мекунад: ҳар гоҳ омӯзгор аз ҳадди намунавӣ зиёд ё кам соат гирад, ранг ва нишон тағйир меёбад — «СЕРБОРӢ!» сурх мешавад. Ҳамаи тарификатсия дар як нигариш дида мешавад ва бо як клик ба варақаи расмии Word/Excel чоп мегардад — ҳамон ҳуҷҷате, ки пештар дастӣ ҳафтаҳо тайёр мешуд. Шаффофият дар он аст, ки ҳар омӯзгор бори худро, ҳар завуч тақсимоти умумиро ва раиси маориф ҳолати пуршавии кадрҳои ҳар мактабро мебинад — пинҳонӣ дар ҳеҷ сатҳ нест.
