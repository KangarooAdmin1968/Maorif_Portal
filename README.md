# Маориф портали — Зафаробод

Бу лоиҳа PyQt6 дастурларини (`main.py`, `sinflar.py`) бирлаштириб, Django + PostgreSQL/SQLite асосида веб-порталга айлантириш учун яратилган.

## 1. Тайёрлаш

PowerShell терминалида лоиҳа папкасида турамиз:

```powershell
cd d:\Desktop\Loihalar\Maorif_Portal
```

## 2. Virtual muhit яратиш

```powershell
python -m venv venv
```

## 3. Кутубхоналарни ўрнатиш

```powershell
venv\Scripts\python -m pip install -r requirements.txt
```

## 4. Маълумотлар базасини яратиш

```powershell
venv\Scripts\python manage.py makemigrations
venv\Scripts\python manage.py migrate
```

## 5. Администратор фойдаланувчисини яратиш

```powershell
venv\Scripts\python manage.py createsuperuser
```

Логин, email ва паролни киритинг. Сўнгра `http://127.0.0.1:8000/admin/` орқали кириб, `UserProfile` ёрдамида ролларни тайинланг:

- **director** — тўлиқ админ (ноҳиявий маориф директори)
- **principal** — мактаб/литсей директори
- **teacher** — муаллим (синф ва фан вобаста киритади)

## 6. Статик файлларни йиғиш

```powershell
venv\Scripts\python manage.py collectstatic --noinput
```

## 7. Лойихани ишга тушириш

```powershell
venv\Scripts\python manage.py runserver
```

Браузерда `http://127.0.0.1:8000/` очинг.

## 8. Ишлаш тартиби

1. Админ панелга киринг (`/admin/`).
2. `Schools` ёки `Муассисаҳо` орқали мактаб/литсей/кӯдакистон қўшинг.
3. `Teachers` ёки `Муаллимон` орқали муаллимларни мактабларга боғланг.
4. `ClassSubject` ёрдамида синфлар учун фанларни кўриш/таҳрирлаш.
5. Синф саҳифасида `📥 Шаблонни юклаб олиш` тугмаси билан Excel шаблонни юкланг, тўлдиринг ва `📤 Excel импорт` билан маълумотларни базага юкланг.
6. Муаллим ролида синф/фан танланиб, баҳо жадвалида 1–10 гacha баҳо киритади.
7. Асосий панелда (`/`) мактаблар, синфлар ва фанлар рейтинги автоматик ҳисобланади.

## 9. Муҳим функциялар

- **RBAC**: `director`, `principal`, `teacher` роллари
- **Синф номларини нормализация**: `10a`, `10-a`, `10 a` → `10-А`
- **Фан номларини нормализация**: `ОДХ`, `OIX`, `OIH` → `ОИХ`
- **Excel импорт/экспорт**: синфлар, хонандагон ва баҳо учун
- **Динамик рейтинг**: мактаблар, синфлар ва фанлар бўйича
- **Тоҷикистон миллий ўқув дастури**: синфларга мос фанлар автоматик юкланади

## 10. Keyingi qadamlar

- PostgreSQL учун `settings.py`да `DATABASES` бўлимини изоҳдан чиқаринг.
- Асосий `main.py` ва `sinflar.py` дан аввалги маълумотларни импорт қилиш учун махсус команда ёки view яратиш.
- Веб-интерфейс дизайнини кенгайтириш (Bootstrap/Tailwind).
- Ҳисоботлар ва PDF экспорт.
